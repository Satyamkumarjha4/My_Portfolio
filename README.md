# Portfolio

[![CI](https://github.com/Satyamkumarjha4/My_Portfolio/actions/workflows/ci.yml/badge.svg)](https://github.com/Satyamkumarjha4/My_Portfolio/actions/workflows/ci.yml)

Full-stack portfolio for Satyam Kumar Jha: a React SPA backed by an Express + Prisma + PostgreSQL API with a protected admin panel for managing content.

- `Frontend/` React 19, TypeScript, Vite, Tailwind 4
- `Backend/` Express 5, Prisma, PostgreSQL, zod, JWT
- `docs/` architecture, API reference, security, deployment, testing, decisions

Start with [docs/README.md](docs/README.md). Quick start: [docs/development.md](docs/development.md).
